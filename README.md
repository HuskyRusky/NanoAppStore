This is an appstore, which you can play 5 games on.
You can play the following games.

1. Guessing game

   Guess a number between 1 and 100 with 11 tries.
   
2. Hang man

   Guess an easy, medium or hard word with 11 tries.

3. Tic-tac-toe

   Play tic-tac-toe against another player.

4. Rock paper scissors

   Play rock paper scissors against the computer or another player, first to win 3 rounds, wins the game.

5. Mastermind

   Try to guess a 4 color code in 10 tries, everytime you guess 4 colors, you see how many colors you got right.
